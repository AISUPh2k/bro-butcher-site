# Размещение сайта БРО на VPS

Сайт, админка и приём заказов работают в Docker. Перед ними стоит Caddy: он отвечает на 80/443 и сам получает HTTPS-сертификат.
Домен остаётся в SpaceWeb, меняется только A-запись. Почту на домене (MX) **не трогать**.

Команды с `ЛОГИН`, `IP_VPS` подставить свои. Пароли никуда не пересылать — вводятся только в терминале.

## 0. Заранее (за день)
- В панели SpaceWeb → «Домены» → DNS для `myaso-sobakam-bro.ru`: если можно, уменьшить TTL у A-записи до 300.
  Тогда переключение разойдётся за минуты, а не часы.
- **Проверить, не входит ли почта на домене в тариф виртуального хостинга.** Если входит — тариф не отключать
  после переезда (или сначала перенести почту), иначе ящики на домене перестанут работать.
- Ящик-отправитель заказов на Яндексе: id.yandex.ru → «Безопасность» → «Пароли приложений» → создать пароль для почты.
  В настройках Яндекс Почты → «Почтовые программы» разрешить доступ по паролю приложения.

## 1. Заказать VPS
Ubuntu 24.04, 1–2 ГБ RAM, от 15 ГБ диска, дата-центр в России, публичный IPv4. Записать `IP_VPS`.

## 2. Резервная копия старого сайта (OpenCart)
```sh
scp deploy/backup-old-site.sh ЛОГИН@77.222.40.7:
ssh ЛОГИН@77.222.40.7 'bash backup-old-site.sh'
mkdir -p ~/site11/backup-old && scp 'ЛОГИН@77.222.40.7:bro-old-*' ~/site11/backup-old/
```
Должны появиться `bro-old-ДАТА.sql` (база) и `bro-old-ДАТА.tgz` (файлы). Не продолжать без них.

## 3. Установка на VPS
```sh
ssh root@IP_VPS
curl -fsSLO https://raw.githubusercontent.com/AISUPh2k/bro-butcher-site/main/deploy/setup-vps.sh
bash setup-vps.sh
```
Скрипт спросит: пароль админки (дважды), ящик-отправитель, SMTP (`smtp.yandex.ru`), пароль приложения, куда слать заказы.
Он ставит Docker и файрвол (22/80/443), создаёт пользователя `bro`, кладёт сайт в `/home/bro/site`, запускает и
включает ежедневный бэкап в `/home/bro/backup-ДАТА.tgz` (хранится 30 дней).

Проверка, что сайт поднялся (до смены DNS HTTPS ещё не будет — это нормально):
```sh
docker ps                                  # bro-site и bro-caddy — Up
docker exec bro-site python3 -c "import urllib.request as u; print(u.urlopen('http://127.0.0.1:8100/').status)"   # 200
docker logs bro-site --tail 20
```

## 4. Переключить домен
SpaceWeb → «Домены» → DNS `myaso-sobakam-bro.ru`:
- A-запись `@` → `IP_VPS`
- A-запись `www` → `IP_VPS` (если есть CNAME на старый хостинг — заменить на A)
- **MX, TXT (SPF/DKIM) и почтовые записи не трогать.**

Проверить, что адрес сменился: `curl -s --doh-url https://1.1.1.1/dns-query 'https://cloudflare-dns.com/dns-query?name=myaso-sobakam-bro.ru&type=A' -H 'accept: application/dns-json'`.
Когда видно `IP_VPS`, Caddy в течение минуты получит сертификат (`docker logs bro-caddy`).

## 5. Проверить на боевом адресе
- https://myaso-sobakam-bro.ru — главная, каталог, карточка товара, зоогостиница, политика.
- Старая ссылка: https://myaso-sobakam-bro.ru/govyadina/obrez-govyazhya-v-kubikah → откроется новая страница товара.
- https://myaso-sobakam-bro.ru/admin/ — вход, вкладка «Заказы».
- Пробный заказ → письмо с `Заказ-1.pdf` пришло; в админке заказ есть, накладная скачивается.
- Удалить пробные заказы, чтобы у Натальи нумерация началась с №1:
  `sudo -u bro rm -rf /home/bro/site/orders/2026 /home/bro/site/orders/counter.txt /home/bro/site/orders/outbox`
- Если письмо не пришло: `docker logs bro-site | grep "письмо не ушло"` — там причина.

## 6. После запуска
- Яндекс Вебмастер: проверить сайт, отправить `https://myaso-sobakam-bro.ru/sitemap.xml`.
- Старый хостинг держать ещё неделю (на случай отката), потом решить с тарифом — см. пункт про почту в разделе 0.
- Сменить пароли, которые пересылались в переписке (почта, хостинг, старая админка).
- Наталье: уведомление в Роскомнадзор как оператор персональных данных (pd.rkn.gov.ru).

## Откат
Вернуть A-записи `@` и `www` на `77.222.40.7` — снова откроется старый сайт.

## Обслуживание
```sh
sudo -u bro bash /home/bro/site/deploy/update.sh   # обновить код; данные из админки не трогаются
docker logs -f bro-site                            # лог сайта и заказов
ls -lh /home/bro/backup-*.tgz                      # ежедневные бэкапы — иногда копировать к себе
```
